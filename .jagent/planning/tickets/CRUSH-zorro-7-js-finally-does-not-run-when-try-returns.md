## Problem

Also in CRUSH-199 (partly stale); this ticket supersedes its finally half. The swc lowering drops the finalizer outright (`finalizer: _`, lower_swc.rs ~571). `function f() { try { return 1; } finally { console.log('fin'); } } console.log(f());` prints `1`; node prints `fin` then `1`. A `return` (and presumably `break`/`continue`/`throw`) leaving a `try` skips its `finally`.

## Success criteria

- [ ] `finally` runs on fall-through, `return`, `break`, `continue` and `throw` out of the `try` and out of the `catch`, matching node on VM and AOT (or AOT loud).
- [ ] A `return` inside `finally` overrides, as in JS.

## Technical approach

- Check how CAST/the frontend lower try/finally (`enter_try`); lower early exits through the finally block (duplicate finally code at each exit, or a pending-completion register).
